## New features

### Server-scoped tool discovery

The [`mcp_search_tools`](/core-concepts/meta-tools) meta-tool now accepts `serverId` and `serverName` parameters to scope discovery to a single connected MCP server. Pass `serverId` when you have the exact ID, or `serverName` to match a human-readable fragment (e.g., `serverName: "database"` matches `Database MCP`). This makes it much easier for an LLM to drill into one integration without sifting through unrelated results.

### Deterministic server listing

`mcp_search_tools` now supports `operation: "list"`. Combined with `serverId` or `serverName`, this returns every tool from a server with `totalCount`, `returnedCount`, and `nextCursor` metadata — ideal for "show me everything this server can do" prompts. See the [Meta-Tools reference](/core-concepts/meta-tools) for the full syntax.

### New `mcp_list_servers` meta-tool

A new [`mcp_list_servers`](/core-concepts/meta-tools) meta-tool lets the LLM enumerate which MCP servers are currently connected, along with their IDs and tool counts. Use it as a fallback when a search returns no matches, then retry with a specific `serverId` or `serverName`. Read more in the [Tool Router guide](/core-concepts/tool-router).

## Updates

### Search tool renamed to `mcp_search_tools`

The primary discovery meta-tool has been renamed from `mcp_search_tool_bm25` to [`mcp_search_tools`](/core-concepts/meta-tools) to better reflect its expanded capabilities (BM25 ranking, semantic search, direct selection, server scoping, and deterministic listing all live behind one entry point). The legacy alias is preserved so existing integrations continue to work.

## Bug fixes

- **Exact tool namespace matching** — Fixed an issue where looking up a tool by its exact `serverId/toolName` pair could fall back to fuzzy matching and resolve the wrong tool when multiple servers exposed similarly named tools.
- **Server name fragment selection** — Fixed inconsistent matching when `serverName` was passed as a fragment (e.g., `"database"` for `Database MCP`). Server scoping is now reliably case-insensitive across search, listing, and direct selection.
