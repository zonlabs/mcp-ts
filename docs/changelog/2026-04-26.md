## Bug fixes

### AG-UI middleware stream stalls

Fixed an issue in the [AG-UI adapter](/ai-adapters/agui) where streamed responses could stall mid-flight, leaving the UI hanging or surfacing `INCOMPLETE_STREAM` errors after a tool call. The middleware now:

- Tracks continuation runs explicitly so the outer stream stays open until the follow-up turn finishes, instead of completing prematurely after the first run.
- Captures content from both streaming chunk events and full content events, so assistant text reconstructed for tool-call continuations is no longer truncated.
- Uses the correct camelCase field names when re-injecting assistant and tool messages into the conversation, so strict LLM providers no longer reject the continuation request.
- Cleans up inner subscriptions deterministically, preventing leaked subscribers when a run errors or is cancelled.

If you've been using the AG-UI adapter with CopilotKit or another streaming UI, upgrade to pick up smoother, more reliable streaming through tool calls.
